PASS 6 — HOW TO ORDER AUDIO AND CERTIFIED TRANSCRIPTS (the human routes)
================================================================
(a) AUDIO RECORDING OF A HEARING - 4th District
    Page: https://www.utcourts.gov/en/court-records-publications/records/transcripts.html  (fetched OK)
    Form: 1100GE "Request for Copy of Audio Recording"
    Submit by email to: recordingrequest4th@utcourts.gov     <-- THE FOURTH DISTRICT ADDRESS
    Fees observed on that page: $15.00 per half-day for the electronic record;
      $10.00 for each recording delivered via the FTR Cloud online system;
      $15.00 per item if placed on USB/disc; plus actual postage if mailed.
    Process: court quotes cost -> you pay -> they release the recording.
    (The inventory already contains 10_6_25_Request_For_Audio_Recording.pdf and
     2_25_26_Request_For_Copy_Of_Audio_Records.pdf - those are OTHER PARTIES using this same route.)
