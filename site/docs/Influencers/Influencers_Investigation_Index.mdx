# Influencers Investigation Index

Mainstream television largely accepted the FBI lone-shooter frame or ignored the case.
**Independent hosts and X researchers** carried the analytical load — flight tracks, ballistics,
GRAMA records, security failures, and motive threads. This memo routes readers without endorsing
every theory any influencer promoted.
