# Security Detail Call Chain

Investigators reconstruct a **graph of calls** rather than a single 911 tape. Claimed nodes include:

1. Pre-event security / logistics traffic  
2. Moment-of / rooftop response radio or phone  
3. **SUV transport** lines ([audio claims](./suv-911-audio))  
4. Possible **cross-org** line to Shapiro security ([claims](./shapiro-security-call))  
5. [Missing 911 production](./missing-911-harpole) disputes  
6. [Dan Flood](/Security_Team/dan-flood) as both text recipient and day-of proximity figure  

## Why a chain page

Individual viral clips isolate one edge of the graph. A chain view asks: **who called whom, at what second, on what system?** That is a FOIA/GRAMA/Fix-Laws problem, not a meme problem.

## Defamation note

Mapping claimed call edges does **not** assert that security staff murdered Charlie Kirk or staged the scene. It asserts that **call records are investigatory objects**.
