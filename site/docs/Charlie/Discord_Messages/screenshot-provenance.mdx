# Screenshot Format and Provenance

When a post claims "Charlie's Discord messages," run a **provenance checklist** before amplifying. Fabricated or misattributed chat images have circulated freely since Charlie Kirk was assassinated, and an unverified screenshot can do more damage to [the investigation](/Charlie/overview) than no screenshot at all.

## Checklist

1. **App chrome** — Discord channel list / @handles vs WhatsApp double-checks vs iMessage bubbles  
2. **Typography** — system fonts vs Canva meme fonts  
3. **Timestamps** — absolute dates vs relative "Yesterday"; timezone  
4. **Participants** — real phone numbers / Discord snowflake IDs vs blank avatars  
5. **Prior publication** — does reverse image search show an earlier meme template?  
6. **Independent confirmation** — named witness (e.g. Kolvet for WhatsApp) or only anonymous accounts?

## Known healthy vs unhealthy examples

- **Healthier**: WhatsApp crops later confirmed by TPUSA spokesman commentary.  
- **Unhealthy**: extreme quotes in generic dark UIs with "Charlie Kirk New" profile labels that Grok and investigators flag as non-matching the verified set.

See [Authenticity, Fakes & Memes](/Charlie/Text_Messages/authenticity-and-fakes).
