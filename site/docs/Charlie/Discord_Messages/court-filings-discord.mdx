# What Court Filings Actually Show

The **State's memorandum supporting bindover** (published in public discussion July 29, 2026 via attorney [@aburkhartlaw](https://x.com/aburkhartlaw/status/2082615978207445283)) numbers message material as:

| Exhibit | Content |
|---------|---------|
| 16 / 16.1 | Twiggs interview / Robinson–Twiggs **texts** |
| **16.2** | **Discord** messages (short excerpt set) |
| 16.3 | Handwritten note |
| 16.4 | Surveillance-related material |

That Discord exhibit is attributed to the **charged suspect's** circle — not to Charlie Kirk. PDF: [state memorandum](/court/bindover/state-memorandum-supporting-bindover.pdf).

## Implication for this Charlie section

There is **no parallel public exhibit series** titled "Charlie Kirk Discord logs" in that memorandum. Charlie's private-message fight lives in **media releases, Owens shows, and TPUSA confirmations**, not in Ex. 16.2. Readers who want Discord *court* detail should open [Tyler Discord Messages](/Tyler_Robinson/Messages/discord-messages).
