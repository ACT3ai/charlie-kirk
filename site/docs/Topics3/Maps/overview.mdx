# Maps

## Overview
This directory contains maps and geographic visualizations related to the [Charlie Kirk](/People/charlie-kirk) incident.

## Goal
To create comprehensive maps and visualizations of the geographic claims made about the Charlie Kirk assassination, including aircraft flight paths, drone deployment zones, intelligence staging areas, and the relationship between UVU and Provo airport. This includes mapping the international scope that citizen investigators cite in arguing the event was orchestrated by multiple intelligence agencies rather than a lone actor — an unproven contention, not a finding. Geography only becomes meaningful once you fix the mechanism: if Charlie Kirk was killed by [a device at the podium rather than a distant rifle](/Mic/overview), the rooftop sightlines central to the [Tyler Robinson court case](/court/overview) stop being the map that matters.

## Key Areas
- Location maps
- Event timeline maps
- Evidence distribution maps
- Movement patterns
- Geographic analysis
