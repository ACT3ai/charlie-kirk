# X search topics — flight data reported erased

This is the **topic list**, not the findings. The write-up of what the searches actually returned is **[X posts on flight data reported erased](/Planes/X-Posts-Flight-Data-Erasure)**.

One topic per query. Every query asks for **full X.com / Twitter posts** — usernames, dates, URLs, complete quotes, screenshots mentioned, which tracker, which tail, which person. **The words "summarize", "summarized", and "summary" do not go in any Grok AI search or X search for this cluster.** A prior run of the [Following topics list](/Planes/following/topics) prefixed every query with "Summarize and get extensive detail". That prefix is what this file exists to stop. We want the posts themselves, not a condensation of them.

## Query rule (do not break this)

* One topic per search.
* Ask for **full post text, usernames, dates, URLs, engagement, attached images/videos**.
* Name Twitter and X.com in the query so the search actually returns posts.
* Name the tail, the tracker, and the person when the topic has them.
* Never insert "summarize", "summarized", "summary", "TL;DR", or "brief overview" into the query.
* Never ask Grok to "condense" or "give the gist". Ask it to **return every distinct post**.

## What this list is not

This is not a per-plane paper. The Egyptian tails share one cluster. The Kirk-family tail shares one cluster. TPUSA-linked domestic tails share one cluster. The question on every row is the same: **did someone on X say a tracking system dropped data, which system, which aircraft, which person, and what were they trying to see.**
