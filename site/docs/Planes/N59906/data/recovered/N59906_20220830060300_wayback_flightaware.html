• Produtos

    Produtos de dados

    • AeroAPI API de dados de voo com status de voo sob demanda e dados de rastreamento de voo.
    • FlightAware Firehose Fluxo de feed de dados de voos para integrações empresariais com dados de voo em tempo real, históricos e preditivos.
    • Foresight Tecnologia preditiva para fortalecer a confiança dos clientes em suas operações
    • Rapid Reports Compre facilmente relatórios históricos entregues por e-mail.
    • Custom Reports Relatórios de dados de rastreamento de voos detalhados e personalizados de caráter consultivo.

    Aplicativos

    • Aviator O pacote de rastreamento de voos decisivo para proprietários e operadores de aeronaves pequenas/aviação geral (GA).
    • Premium Subscriptions Uma experiência de acompanhamento de voo personalizada com alertas ilimitados e muito mais.
    • FlightAware Global A plataforma de rastreamento de voos padrão do setor para proprietários e operadores da aviação executiva (BA).
    • FBO Toolbox Rastreamento de voos abrangente para aprimorar suas operações de FBO e aumentar as vendas.
    • FlightAware TV Mapas da FlightAware TV em tela cheia para operadores ou FBOs.
    • GlobalBeacon Rastreamento e alerta global em conformidade com o padrão GADSS para companhias aéreas e operadoras de aeronaves.
