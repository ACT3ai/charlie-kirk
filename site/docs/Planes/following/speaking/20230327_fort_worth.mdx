**Charlie** at **Texas Christian University** (Fort Worth, TX) on **2023-03-27**. Date certainty: this is a sourced event date, not a podcast-release proxy.

## The pairing, in one sentence

This page records a [TPUSA](/TPUSA/overview) / Charlie Kirk speaking appearance so the [following-pattern](/Planes/following/overview) can be tested against a real location, not a guessed one. It is not itself an overlap with [SU-BTT](/Planes/SU-BTT/overview) or [SU-BND](/Planes/SU-BND/overview). One campus stop is not evidence of shadowing; the claim, if any, is the repetition across many stops.

## Where this page fits

Every row on the [speaking index](/Planes/following/speaking/overview) fixed this way — a TPUSA press-release date replacing a podcast-release date five days later — narrows the window the [following-pattern claim](/Planes/following/overview) has to survive, and it feeds straight into the [event-by-event aircraft ledger](/Planes/following/TPUSA_events) and the [73-overlap reconstruction](/Planes/following/73_overlaps). Texas Christian sat on the same [Turning Point USA](/TPUSA/overview) spring tour that built the [campus operation](/campus_university/overview) Charlie Kirk ran until his last event, and the [political pressure field](/political_context/overview) that later attached to those bookings is documented separately from the tour dates themselves. If you read one page next, make it the [overlap window definition](/Planes/following/Overlap_Window_Definition): the compilers counted a jet within 50 to 100 miles and plus or minus three days as an overlap, which is why a five-day date error changes the answer for tails like [SU-BTT](/Planes/SU-BTT/overview).
