**Charlie** at **University of Kentucky** (Lexington, KY) on **2023-03-08**. Date certainty: this is a sourced event date, not a podcast-release proxy.

## The pairing, in one sentence

This page records a [TPUSA](/TPUSA/overview) / Charlie Kirk speaking appearance so the [following-pattern](/Planes/following/overview) can be tested against a real location, not a guessed one. It is not itself an overlap with [SU-BTT](/Planes/SU-BTT/overview) or [SU-BND](/Planes/SU-BND/overview). ## Where this page fits

Kentucky is a four-day correction of the same kind — 12 March 2023 in the source data, 8 March in fact — and four days is wider than the [plus-or-minus-three-day overlap window](/Planes/following/Overlap_Window_Definition) itself, so this single fix can create or destroy a row in the [following-planes tally](/Planes/following/overview) and in the [speaking catalog](/Planes/following/speaking/overview) that feeds it. That sensitivity is why this material exists as pages rather than a summary, and it is the same reason the rest of the site keeps [court filings](/court/overview), [official statements](/Legal/Official-Statements) and [commentary](/Influencers/overview) in separate places. The payoff page is [the overlap recovery test](/Planes/Flight-Data-Recovery/Overlap-Recovery): all 69 testable aircraft-and-date pairs from [the reconstructed spreadsheet](/Planes/following/73_overlaps) were pulled against both free daily ADS-B archives, twenty-three came back with a primary trace, and the page says exactly which is which.
