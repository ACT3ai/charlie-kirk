## Where this page fits

This row is a podcast release date, not an event date, and it is the same Briahna Joy Gray debate already recorded on [19 May](/Planes/following/speaking/20220519_tpusa_debate_night) — so it must never be used to compute a same-day pairing anywhere in the [following-planes record](/Planes/following/overview) or the [73-overlap reconstruction](/Planes/following/73_overlaps).
