**TPUSA** at **Louisiana State University** (Baton Rouge, LA) on **2025-10-27**. Date certainty: Charlie Kirk was already dead. TPUSA and/or Erika Kirk continued the tour with guest speakers.

## The pairing, in one sentence

This page records a [TPUSA](/TPUSA/overview) / Charlie Kirk speaking appearance so the [following-pattern](/Planes/following/overview) can be tested against a real location, not a guessed one. It is not itself an overlap with [SU-BTT](/Planes/SU-BTT/overview) or [SU-BND](/Planes/SU-BND/overview).
