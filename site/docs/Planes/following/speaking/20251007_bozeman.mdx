# Turning Point Tour — Montana State University

**TPUSA** at **Montana State University** (Bozeman, MT) on **2025-10-07**. Date certainty: Charlie Kirk was already dead. TPUSA and/or Erika Kirk continued the tour with guest speakers.

This page records a [TPUSA](/TPUSA/overview) / Charlie Kirk speaking appearance so the [following-pattern](/Planes/following/overview) can be tested against a real location, not a guessed one.
