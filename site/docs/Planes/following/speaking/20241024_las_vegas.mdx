A campus morning with a crowd figure Kirk published himself, then a [Turning Point](/TPUSA/overview) rally the same day in the same city — and resolving it corrected the source spreadsheet, which had filed this date as a Georgia rally, meaning one row feeding the [overlap reconstruction](/Planes/following/73_overlaps) pointed at the wrong state before the [speaking index](/Planes/following/speaking/overview) and the [Following](/Planes/following/overview) file reworked it.
