STAGE 1 - CHECK THE MONEY AND THE TERMS BEFORE THE FIRST CALL
====================================================================

* State which vendor, which plan, whose account, and roughly what the run costs.
  A per-query API is easy to run into three figures by accident.
* Read the vendor's terms of use for redistribution BEFORE pulling. Record in
  {KNOWLEDGE_FILE} what the terms actually say, quoted, with the date read.
* Credentials come from the environment, never from a file in this repo, and
  never from a page. Never commit a key. Never print a key.
* If credentials are absent, DO NOT invent a workaround, do not scrape the
  vendor's website to get around the paywall, and do not use an unofficial
  endpoint the vendor has not published. Stop, and record in {KNOWLEDGE_FILE}
  exactly which question is blocked on which credential.

====================================================================

* Commercial responses generally may NOT be republished verbatim. Most terms let

* Where a licence is unclear, treat it as restrictive.
* Add a row to {SOURCES_CSV} for every vendor query, with evidence_class
