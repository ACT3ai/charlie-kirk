STAGE 1 - DECIDE WHAT THIS RUN IS FOR
====================================================================

* A run of this prompt is one of four things. Pick one and say which:
  * BACKFILL - pull claimed dates from {FLIGHTS_CSV} and {OVERLAPS_CSV} that have
    no primary trace yet.
  * NEW CLAIM - somebody published a new date or a new tail; go get it.
  * RECHECK - re-pull something we already have, to see whether it is still
    there. This is how scrubbing gets caught.
  * DISCOVERY - go looking for a source we do not have yet.
* Never silently do all four. A run with a stated purpose produces a page; a run
  without one produces a pile of JSON.

====================================================================

* The clients in {CODE_DIR} already exist. Read {CODE_DIR}_README.md and use

  * wayback.js - Internet Archive snapshots. The scrubbing detector.

* If a new source turns up, add a new client next to those. Match their shape:
  raw response saved, .meta.json beside it, never overwrite a previous pull.
* Prefer an installable open-source CLI over hand-rolled code where one exists,

====================================================================
STAGE 4 - WRITE DOWN WHAT YOU COULD NOT GET
====================================================================

* Every claimed flight that returned nothing gets recorded. Write or update
  MISSING_DATA.md in the aircraft directory and in the overlap directory.
* Each entry states: the tail, the UTC date, the source and endpoint tried, the
  HTTP status, and WHO CLAIMED THE FLIGHT and where they claimed it.
* Then state the honest reading, every time: an absent trace means the network
  holds no trace. It does not establish that the aircraft did not fly and it does
  not establish that a transponder was switched off. Coverage gaps, a parked
  aircraft, and a wrong claimed date all look exactly like this.
* Separate two different things and never blur them:
  * NEVER HAD IT - the source never held this and we have no evidence it did.
  * NO LONGER HAS IT - we or the Internet Archive can show it was once there.
  The second is a finding about the record. The first is a gap in coverage.
