# Analysis Documentation

## Overview
This directory contains comprehensive analysis and documentation related to the Charlie Kirk investigation.
The subject of that analysis is how Charlie Kirk was killed at Utah Valley University on September 10 2025, a question the [microphone and explosive evidence](/Mic/overview) reopened after the initial official account. A parallel documentary record comes out of the [court case in Utah County](/court/overview), which this section treats as a source rather than as a conclusion.
