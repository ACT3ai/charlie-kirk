This is a portrait-oriented screenshot of a mobile user interface displaying a post on the social media platform X (formerly Twitter). The post sets out a multi-paragraph allegation that an alibi published by [**Cabot Phillips**](/US_Intelligence/Fort_Huachuca/Cabot_alibi) was faked, with the poster's own bulleted list of what it calls "proof."
