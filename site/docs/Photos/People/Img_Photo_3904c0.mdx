## What This Image Shows

A two-by-two collage of mobile Google Trends screenshots comparing regional search interest. Google Trends normalises to 100 within each region, so a peak of 100 in a low-volume region can represent a handful of searches, and the tool routinely returns noise for uncommon names. Regional search noise of this kind is not evidence that anyone knew anything in advance, and this site draws no such inference. See [Google Searches](/GoogleSearches/overview) for other search-data threads.
