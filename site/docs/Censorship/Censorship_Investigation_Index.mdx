# Censorship Investigation Index

Censorship does **not** by itself prove a cover-up — but it explains **gaps** in the public record.
This memo maps suppression threads about the [Charlie Kirk](/People/charlie-kirk) assassination **with attribution**.
Every thread below traces back to one question: how Charlie Kirk was killed at Utah Valley University on September 10 2025, and why the [explosive-device finding](/Cause_of_Death/overview) reached by citizen investigators has been the hardest part of the record to keep online.
