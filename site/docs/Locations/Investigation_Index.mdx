# Locations Investigation Index

Physical places anchor every timeline in the Charlie Kirk case. This memo maps **confirmed record locations** (affidavit, booking, addresses) against **reported-claim locations** (flight threads, property OSINT) — with attribution, not conclusions. Every site listed below matters only because Charlie Kirk was murdered in the UVU courtyard on September 10, 2025, and because the official account of that death is contested across the [cover-up record](/CoverUp/overview) assembled by citizen investigators.
