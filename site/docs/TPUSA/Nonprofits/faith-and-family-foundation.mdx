## Connection to the Charlie Kirk case

This Texas charity is logged because the **Twiggs** surname recurs in the investigation — the notes elsewhere reference the family name in connection with the accused's circle (**Lance Twiggs** is named as [Tyler Robinson](/Killer/overview)'s partner). Whether the **Faith and Family Foundation Charity** (a Houston-registered nonprofit with directors **Amy, Jerry, and Mikayla Twiggs**) has any actual relationship to those individuals is **not established** — this is a **name match** flagged for verification, nothing more.

There is **no evidence** connecting this charity to TPUSA or to the assassination. It is recorded so researchers can confirm or dismiss the surname overlap against public records.
