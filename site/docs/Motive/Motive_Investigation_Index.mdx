## Public commentary

Public discussion has grouped the reported motive theories into four clusters:

1. **Donor / Israel pressure** (Owens–Ackman–Hamptons narrative)
2. **Lone-actor ideological** (state case against Tyler Robinson)
3. **Intel-service / geopolitical** (Huachuca, flights, foreign policy)
4. **Internal org conflict** (communications and succession politics)

None of these is proven as *the* motive for assassination by this site.
