Charlie_Kirk_AI_Inbox.txt  —  AI WRITES HERE. NEVER TO Charlie_Kirk.txt.
================================================================================

WHAT THIS FILE IS
  Charlie_Kirk.txt is READ-ONLY TO AI as of 2026-07-30. Any new investigation
  text an AI skill would previously have appended to Charlie_Kirk.txt gets
  appended HERE instead, append-only, in the same equal-sign section format.

  Bryan merges from this file into Charlie_Kirk.txt by hand, when and if he
  wants to. AI never merges. AI never deletes from this file either.

FORMAT
  Each entry uses the normal section header format, plus a line naming the
  Charlie_Kirk.txt section the AI believes it belongs under:

      =============== Section Title ==================
      [BELONGS UNDER Charlie_Kirk.txt SECTION: <name of existing section>]
      <content>

WHY THIS EXISTS
  An audit of the git history on 2026-07-30 found four separate occasions where
  AI damaged Charlie_Kirk.txt — deleting a rumor entry, inserting a defamation
  hedge into a line about a named family, rewriting a sentence, and replacing a
  section header and its content. All four were restored. This file removes the
  reason for AI to ever open Charlie_Kirk.txt for writing again.
